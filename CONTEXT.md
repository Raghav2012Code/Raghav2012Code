# Raghav2012Code profile

This repository carries the GitHub profile README for Raghav2012Code: the markdown document itself plus the automation that keeps its bonsai art fresh.

## Language

**Profile README**:
The markdown document in this repository that GitHub renders on the profile page.
_Avoid_: bio, profile page

**Bonsai**:
The pixel-art tree grown from the commit history, rebuilt every day and floated beside the about section.
_Avoid_: tree, plant

**Bonsai pipeline**:
The daily GitHub Action that grows the tree and refreshes the art it is drawn into.
_Avoid_: bot, cron job

**Sheet**:
The retired SVG panel grid (hero, record, projects and toolchain bands with interlocked borders) that the README was built from before the rework.
_Avoid_: old design, v3

**old-design**:
The branch that archives the sheet exactly as it rendered, kept for recovery.
_Avoid_: backup branch
