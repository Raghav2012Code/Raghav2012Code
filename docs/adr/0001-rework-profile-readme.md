# Rework the profile README from the SVG sheet to a markdown-first layout

Status: accepted (2026-10-14)

The README was a hand-built SVG sheet: hero, record, projects and toolchain panels interlocked with 1.5px borders, the whole document images. Every edit meant regenerating artwork, GitHub search and assistive tech could only read alt text, and the design lived or died with this repository's own tooling. We replaced it with a markdown-first layout modelled on the reference profile README (h2 greeting, italic credential lines, shields.io badges, an about code block with the bonsai floated to its right, a connect line, and a links row). The sheet is archived untouched on the `old-design` branch and its assets stay in `assets/`; the record, projects and toolchain copy it carried left the README with it. A hybrid (new hero above the surviving sheet) was rejected because two visual systems in one page read as a seam, and patching the sheet was rejected because the bonsai had to move out of its side-build cell into the hero slot anyway. The bonsai composition script now serves the hero float; its output is unchanged.
